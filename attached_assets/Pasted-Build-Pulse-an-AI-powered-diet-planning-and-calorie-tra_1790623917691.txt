Build "Pulse" — an AI-powered diet planning and calorie tracking web app.
This is Phase 1 (MVP) of a larger fitness platform. Build ONLY what is
specified here — do not add social features, GPS tracking, or workout videos.

== WHAT IT IS ==
A mobile-first Progressive Web App (PWA) where users:
1. Photograph their meals → AI instantly calculates calories and macros
2. Get AI-generated personalized meal plans (including Lebanese/Middle-Eastern food)
3. Chat with an AI nutrition coach
Core promise: "Snap your plate. Know your numbers. Get your plan."

== TECH DIRECTION ==
- Full-stack web app: React frontend, Node/Express backend, PostgreSQL database
- Mobile-first responsive design (375px width is the primary target; must also
  work on desktop)
- PWA: installable, app icon, splash screen, works offline for viewing history
- Auth: email + password with JWT sessions
- Payments: Stripe subscriptions ($9.99/mo or $59.99/yr, 14-day free trial)
- AI: use Replit AI Integrations (OpenAI) for vision-based photo analysis and
  the coaching chat — do NOT ask me for API keys, use the built-in integration
- Camera: use the device camera via browser for meal photos and barcode scanning

== DESIGN ==
- Dark theme: background #07090C, cards slightly lighter, electric lime green
  #A3E635 as the accent color
- Modern athletic aesthetic: bold headings (Space Grotesk font), clean body text
  (Inter font), generous spacing, rounded cards (16px), large touch targets (44px+)
- Brand motif: a subtle ECG heartbeat line graphic
- Bottom tab navigation on mobile (5 tabs): Home, Log, Plan, Coach, Profile
- Bilingual: full English + Arabic interface with a language toggle
  (Arabic layout must be proper RTL)

== SCREENS & FEATURES ==

1. ONBOARDING (first launch)
   - Welcome screens explaining the photo-logging magic
   - Collect: goal (lose / maintain / gain), age, sex, height, weight, activity
     level, dietary preferences (halal, vegetarian, allergies), country
   - Calculate daily calorie + protein/carb/fat targets (Mifflin-St Jeor equation)
   - Language selection (English/Arabic) at the start
   - Show the "wow moment" immediately: let them photograph a meal and see the
     AI analysis BEFORE asking them to create an account

2. HOME (daily dashboard)
   - Calorie ring: consumed vs target (lime green fills up)
   - Macro breakdown: protein / carbs / fat progress bars
   - Today's logged meals list with photo thumbnails
   - Water tracker (tap to add glasses)
   - Weight log with mini trend chart
   - AI daily insight card: one personalized observation about their eating pattern

3. LOG (the core feature — make this feel magical)
   - Three logging modes: PHOTO (primary), BARCODE SCAN, MANUAL SEARCH
   - Photo flow: take/upload photo → AI vision analyzes → returns dish name,
     estimated calories, protein/carbs/fat, portion size, AND a confidence score
     (low/medium/high) → user can adjust portion or correct items → confirm to log
   - Barcode flow: scan → look up nutrition database → confirm
   - Manual: search food database including Lebanese dishes (manakish, tabbouleh,
     hummus, kibbeh, fattoush, shawarma, labneh, mjaddara, knefeh...)
   - Meals grouped by breakfast/lunch/dinner/snacks
   - "Frequent meals" quick-add and copy-yesterday option

4. PLAN (AI meal planner)
   - Weekly meal plan generated by AI matching the user's calorie/macro targets
     and dietary preferences
   - Each meal card: name, photo placeholder, calories, macros, simple recipe
   - Swap button: regenerate any single meal with constraints ("no fish", "cheaper")
   - Auto-generated grocery list for the week, grouped by category
   - "Log this meal" button connects plan → diary

5. COACH (AI chat)
   - Conversational AI nutrition coach with memory of the user's data:
     today's intake, targets, weight trend, preferences, logged meals
   - Suggested prompt chips: "Why am I not losing weight?", "High-protein
     Lebanese dinner ideas", "Plan my meals around my 8pm gym session"
   - Coach answers reference the user's actual numbers, not generic advice
   - Coach can modify the meal plan or targets when the user asks

6. PROFILE
   - Account info, goals, targets (editable, recalculates plan)
   - Subscription status + manage billing (Stripe customer portal)
   - Language toggle, gentle mode toggle (hides calorie numbers, shows
     qualitative guidance instead)
   - Partner code field: entering a valid gym code unlocks premium
     (this is for our B2B gym partnerships — just the code mechanism, no portal)
   - Privacy: delete my data, export my data
   - Legal: "Pulse provides general wellness guidance, not medical advice"

== MONETIZATION LOGIC ==
- Free: manual logging + basic diary, 3 photo analyses per day
- Premium (Pulse AI): unlimited photo logging, barcode scan, AI meal plans,
  grocery lists, AI coach, daily insights
- Paywall appears: after the 3rd daily photo analysis, when opening Plan or Coach
- Trial: 14 days free, then $9.99/mo or $59.99/yr via Stripe
- Valid partner code = premium without payment

== DATABASE TABLES ==
users (auth, profile, targets, language, partner_code, stripe_customer_id)
meals (user, date, type, photo_url, items[], calories, macros, source)
foods (name, name_ar, barcode, calories, macros, category) — seed with 200+
common foods including Lebanese dishes
meal_plans (user, week, meals[], grocery_list[])
chat_messages (user, role, content, timestamp)
partner_codes (code, gym_name, active)
weight_logs, water_logs

== GUARDRAILS (mandatory) ==
- Never suggest daily calories below 1200 (women) / 1500 (men)
- No shame language anywhere; all messaging is supportive
- If user language suggests disordered eating, coach responds supportively and
  suggests professional help resources
- Show confidence scores on ALL AI calorie estimates; never claim precision
- Health data encrypted at rest; no data sharing with third parties

== DEFERRED — DO NOT BUILD (future phases) ==
GPS/activity tracking, workout programs, social features, chat between users,
wearable sync, gym admin portal, exercise videos

== ACCEPTANCE CRITERIA ==
- I can photograph any meal and get calorie/macro estimates in under 10 seconds
- The AI coach knows my targets and today's intake without me repeating them
- A full week meal plan generates in one tap and respects my calorie target ±10%
- Arabic mode flips the entire layout to RTL correctly
- Paywall and Stripe checkout work end-to-end in test mode
- Installable as PWA on a phone home screen
